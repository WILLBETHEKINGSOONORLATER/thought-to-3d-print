# 想啥印啥 · Thought to 3D Print

> 一句话，得到一个能直接在你拓竹 App 里打开的 3D 模型。

给 AI 助手用的一份技能（Skill）。它管两件事：

**① 场景件**——「文生图 → 去水印 → 图生3D → 摆正 → 在 Bambu Studio 里打开」
**② 精确配合件**——「量尺寸 → 参数化建模 → 自检 → 在 Bambu Studio 里打开」

不用会建模。不用会写代码。**不用装任何东西。**

---

## 这是什么

Skill（技能）可以理解成给 AI 助手装的一份"专业操作手册"——装上之后，你只要说一句"帮我把这只猫做成 3D 模型并在拓竹里打开"，它就知道该按什么步骤做、该注意什么坑。

这个仓库就是一份这样的手册，专门管**从想法到 3D 打印模型**这一段。

---

## 两种用法，先说清区别

| 你要的东西 | 举几个例子 | 助手怎么做 |
|---|---|---|
| **场景件**（好看） | 摆件、手办、公仔、造型挂件 | 画一张参考图 → AI 把它变成 3D 模型 |
| **精确配合件**（能装东西） | 耳机壳、录音笔壳、收纳盒、支架 | 量好尺寸 → **算**出模型，内腔、开孔、壁厚全部受控 |

**为什么配合件不能靠"生成"？** 因为生成出来的东西是实心的，没有内腔、没有真孔、尺寸也没法精确控制——**东西塞不进去，麦克风也收不到声**。这类件必须用"算"的。

你不用自己判断，直接说需求就行，助手会自己选路；拿不准它会问你一句。

---

## 它最特别的地方：AI 会主动问，而且问在点子上

大多数 AI 是"你说一句、它闷头做完、给你个结果"。这个 skill 反过来 —— 它**一路停下来问你**：

| 什么时候 | 它主动做什么 |
|---|---|
| **开工前** | 先问你是要**场景件**（摆件、手办这类，只管好看）还是**精确配合件**（收纳架这类，要装东西、尺寸必须准）；再问你**打印机什么型号** |
| **动手前** | **场景件**：它把形状细节列成选项让你挑（姿态、表情、比例、配饰、底座、多大），你也可以直接说你想要的 |
| | **精确配合件**：它把关键尺寸列成一张表让你过目（内腔多大、留了多少松量、哪里开孔） |
| **每做完一件** | 参考图、3D 模型、准备打开的文件 —— 每出一个就停下来问一句「可以吗」 |
| **你不知道的时候** | 它**自己上网查**；查不到才问你；你也不知道，它就按最保守的估，**并明确告诉你这是估的** |

**诀窍就在这**：场景件用**图**对齐（图比文字准），精确配合件用**数**对齐（数比图准）。它知道该拿什么东西给你确认。

## 它能做到什么

✅ 场景件：你说一句描述 → 它把形状细节列成选项让你挑 → 生成概念图 → 转成 3D 模型 → 自动在你电脑上打开拓竹 App

✅ 精确配合件：你说要做什么壳、装什么 → 它问你几个尺寸 → 算出一套零件 → 自动在你电脑上打开拓竹 App

✅ 自动处理：背景纯净度、水印、模型摆放姿态、文件格式、**配合间隙、开孔透气、卡扣力度**

✅ **每出一个新东西都会先给你看**——参考图、尺寸表、3D 模型、准备打开的文件，都会停下来告诉你一声、问你可不可以，你点头才继续。

✅ 避开常见的坑：模型尺寸超机器、参数设置浪费材料、格式不兼容、**壳子装不进去、开孔位置捂住了麦克风**

---

## 它不做什么

❌ **不做切片。**

终点停在「模型在拓竹 App 里打开」。切片（把模型切成打印机认识的指令）不在范围内，在 App 里完成即可。

**模型打开后，剩下的就是调参数、加支撑、点切片，跟平常一样。**

## 安装（约 1 分钟）

### 前置条件只有一条

你的电脑上装了**拓竹的 Bambu Studio**（下载：https://bambulab.cn/download）。

**除此之外不需要任何东西**——不需要装 Python，不需要装任何库，不需要打开终端。

> 精确配合件那条路需要在电脑上跑一点计算，但**那也是装 skill 的 AI 助手自己准备的事，跟你无关**。

### 装法：把整个文件夹拖进去（推荐）

1. 在本页右上角点绿色 **Code** 按钮 → **Download ZIP**
2. 解压，得到 `thought-to-3d-print` 文件夹
3. 把这个**文件夹**直接拖进你的 AI 助手对话框，告诉它「装上这个技能」

**⚠️ 要拖整个文件夹，不是只拖 `SKILL.md`。** 文件夹里除了 SKILL.md，还有 `scripts/`（建模和环境脚本）和 `references/`（详细规则），缺了配合件那条路会跑不起来。

### 其他装法

**命令行**：

```bash
mkdir -p ~/.workbuddy/skills
git clone https://github.com/WILLBETHEKINGSOONORLATER/thought-to-3d-print.git \
  ~/.workbuddy/skills/thought-to-3d-print
```

**其他 AI 工具**：把整个文件夹放进它读取 skill 的目录，主文件名必须叫 `SKILL.md`。

## 怎么用

装好之后，直接跟你的 AI 助手说话就行。

**做场景件**：

> 帮我把一只戴围巾的狮子做成 3D 模型，在拓竹里打开

或者更具体：

> 生成一个 64mm 高的卡通柴犬 3D 模型，要在拓竹 App 里打开

**做精确配合件**：

> 给我的安克 AI 录音豆做个 3D 打印外壳，形状像一本书，挂在书包上，要保证收音

这种它会反过来问你几个尺寸（豆子多大、多厚、哪里出声、打算怎么充电），你照实说就行；不知道的它自己上网查。

### 整个对话大概长这样

| 回合 | 你说 | 它做/问 |
|---|---|---|
| 1 | 「做个戴围巾的狮子，拓竹里打开」 | 先确认走哪条路 + 问你打印机型号 |
| 2 | 「H2C」 | **列形状细节选项**：姿态站位/坐/趴？表情？要不要围巾？做多大？→ **停下** |
| 3 | 「坐着、呆萌、要围巾、64mm」 | 画参考图 → **停下**：「可以吗？」 |
| 4 | 「可以」 | 转成 3D 模型 → **停下**：「形状对吗？」 |
| 5 | 「可以」 | 报尺寸、说装得下 → **停下**：「现在打开吗？」 |
| 6 | 「打开」 | 拓竹 App 自己弹出来，模型躺在打印板上 |

## 打印前你可能想知道

模型在拓竹 App 里打开后，切片参数可以这样设（这些是实测出来的最优值）：

| 参数 | 建议 |
|---|---|
| 层高 | 0.20mm Standard |
| 填充 | 10%（摆件）/ 15~20%（要受力） |
| **支撑** | **树状（自动）**，阈值 30°，勾「移除小悬空」 |

关于支撑有个实测对比（同一个模型）：

| 支撑类型 | 打印耗时 |
|---|---|
| **树状支撑** | **2h37m** ← 最好 |
| 无支撑 | 2h39m（有塌陷风险） |
| 普通支撑 | 3h40m |

树状支撑同时赢了速度、用料和表面质量。

**材料**：摆件用 PLA，需要韧性/耐热的用 PETG。

## 常见问题

**Q：模型打开的姿势是歪的？**
A：跟助手说"把模型摆正"。AI 生成的模型原点位置随机，这是正常现象，一句话就能修。

**Q：模型显示红色 / 提示需要修复？**
A：正常，直接在 App 里点修复就行，不影响打印。

**Q：生成的模型糊成一团？**
A：多半是第一步的参考图没画好。让助手重画——**白底、单主体、正面视角、无遮挡**，这几点最关键。

**Q：我完全不懂 AI 工具，能用吗？**
A：这份 skill 需要你先有一个能装 skill 的 AI 助手（比如 WorkBuddy）。如果你还没有，建议先试试，上手比想象中简单。

**Q：我想做的壳子，AI 会说做不了？**
A：不会。它会问你几个尺寸，然后"算"出来。如果它建议你改用别的方式，多半是你其实要的是场景件——那就走生成那条路。

**Q：做出来的壳，装进去东西会不会晃 / 会不会塞不进？**
A：这类尺寸是算出来的，不是猜的。助手会给你一张尺寸表（内腔多大、留了多少松量），确认完才开始做。

**Q：壳子捂住麦克风怎么办？**
A：这正是"算"比"生成"强的地方——开孔率、孔道长度都是设定好的数值。你只要告诉助手「哪里要出声」，不知道具体位置就说「不知道」，它会四个方向都开孔。

**Q：能自动出打印文件吗？**
A：不在范围内。原因见上面「它不做什么」。

## 为什么不做全自动切片

试过。命令行切片的坑比想象中多：

- 部分机型的可打印高度会被误读成固定值，大模型直接切不出来，报错信息还会误导你去改模型
- 多喷嘴机型（如 H2C、H2D）的耗材映射在命令行下会失败
