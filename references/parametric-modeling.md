# 路径 B：精确配合件 → 参数化建模

这是 `SKILL.md` 里"两条路径"中第二条的完整说明。**走这条路之前必须先读完本文。**

---

## 1. 先判断：这个件该走 A 还是 B

| 用户要的是… | 走哪条 | 为什么 |
|---|---|---|
| "做一个狮子摆件 / 手办 / 造型挂件" | **A · 文生图→图生3D** | 要的是**像什么**，形状有机、无内部结构 |
| "给我的耳机 / 录音豆 / 药盒 / 传感器做个壳" | **B · 参数化建模** | 要的是**装得下 + 透气 + 尺寸准** |
| "一个能卡在桌子边上的手机支架" | **B** | 有配合尺寸（板厚）、有受力面 |
| "一个有内腔的收纳盒" | **B** | 内腔、壁厚都是尺寸问题 |
| 说不清 | 问一句："**这个东西是要塞别的东西进去，还是只是好看？**" | 塞东西→B，好看→A |

**为什么 B 不能用图生3D 顶替**（这是最常见的一类误判）：

图生3D 是从像素推几何，产出的是**一整块实心或薄壳**：

| 这个件的要求 | 图生3D 能不能给 |
|---|---|
| 内腔（物件要塞进去） | ❌ 没有内腔，出来是实心的 |
| 真实通孔（麦克风要透气） | ❌ 没有孔，纹理不是通孔 |
| 配合精度 ±0.1mm 级 | ❌ 尺寸不可控，导出要自己猜着缩放 |
| 改一个尺寸重出 | ❌ 要重跑整条生成，慢、花额度、结果还不一定对 |

一句话：**图生3D 管"外表像什么"，参数化建模管"里面装得下什么、哪里透气"。**

## 2. 路径 A / B 的步骤对照

| 步骤 | 路径 A（造型件） | 路径 B（配合件） |
|---|---|---|
| 0 确认机型 | ✅ 一样 | ✅ 一样 |
| 1 文生图参考图 | ✅ 核心步骤 | ⭕ **可选**：只想定外观时可以出一张给用户看 |
| 2 去水印 | ✅ | — 用不到 |
| 3 图生3D | ✅ 核心步骤 | ❌ **替换为 B1~B4** |
| 4 摆正脚本 | ✅ | ⭕ 可选：脚本生成的模型本来就居中贴地，一般不用跑 |
| 5 拓竹 App 打开 | ✅ 一样 | ✅ 一样 |

第 5 步之后的一切（切片建议、材料表、常见问题）两条路通用。

## 3. 流程

### B1 · 量尺寸（先问，别猜）

**必须先拿到这些数**，缺一个都别开始建模：

| 要问的 | 举例（安克 AI 录音豆 D3200） | 拿不到怎么办 |
|---|---|---|
| 物件的**直径 / 长宽** | Ø23.2 mm | 让用户拿卡尺量；或联网查型号规格 |
| 物件的**厚度 / 高度** | 13.45 mm | 同上 |
| 物件上**哪里有孔、哪里要出声** | 双 MEMS 全指向麦克风 | **不知道就直接全方位开孔**（见 §4.2） |
| 物件**怎么充电** | 侧面充电触点 → 充电时要能取出来 | 影响开合方式选择 |
| 外壳**多大 / 什么形状** | 一本书，挂书包上 | 用户没说就自己定，定完告诉他 |
| 有没有**凸起物**（磁吸垫片、按键） | 背面磁吸垫片可张开 | **必须问闭合/张开后的最大厚度** |

> ⚠️ **不要凭印象填尺寸。** 差 0.5mm 就是"塞不进去"或"晃得响"。
> 联网查规格时，以厂商官方页面为准；查不到就让用户量，量不了就**按最保守的估并明确告知这是估的**。

### B2 · 定开合方式（必须让用户选）

物件要能取出来（充电、换卡），所以壳子必须能开。三种做法：

| 方式 | 优 | 劣 | 什么时候推荐 |
|---|---|---|---|
| **一体卡扣** | 无额外零件，打印完直接用 | 反复开合会磨损、装配要用力压 | **默认推荐**（快、省事） |
| 磁铁吸合 | 开合顺手、可反复 | 要买磁铁、要留磁铁位、要胶水 | 用户愿意买配件 |
| 螺丝 | 最结实、可反复 | 要买螺丝 + 热熔铜螺母，件厚 | 需要结构强度 |

用户选完再往下。**这一步是路径 B 的"质的提升"节点之一。**

### B3 · 确认参数表（🛑 停下来给用户看）

在写代码之前，把**将要用的关键尺寸列成一张表**发给用户确认：

> 「我按这些数做：内腔 Ø24.0（你那个豆子 Ø23.2，每边留 0.4 松量）／侧面敞开 47% 保证收音／封面封底各开 Ø19 圆窗／外形 62×46×19mm／一体卡扣。有要改的吗？」

用户点头再动手。**这一步能省掉一次白干。**

### B4 · 跑脚本出件

```bash
# 1) 环境（AI 自己准备，用户不参与；只需做一次）
python3 <skill目录>/scripts/setup_env.py        # 输出里会打印 venv 的 python 路径

# 2) 改参数：打开 scripts/param_shell.py，改最上面【参数区】
#    改完先干跑一遍看数值对不对，不写文件
<venv>/bin/python <skill目录>/scripts/param_shell.py --report

# 3) 数值没问题再真出件
<venv>/bin/python <skill目录>/scripts/param_shell.py --out ./out
```

产出三个文件：`body.stl`（下盆）、`lid.stl`（顶盖）、`shell.3mf`（两件合装，一次拖进拓竹 App）。

### B5 · 自检（必做）

`--report` 会打印这些，**每一条都要过一遍再交付**：

- 每个零件的 **水密**（watertight，模型完全封闭、没有破洞）✅
- 每个零件的 **体积为正** ✅（为负说明法线翻了，切片器会认成空壳）
- **内腔直径** ≥ 物件直径 + 2×配合间隙
- **内腔净高** ≥ 物件厚度 + 余量
- **有效孔长** ≤ 0.8mm（做声学件时）
- **侧面敞开率** ≥ 40%（麦克风位置不确定时）
- **压入所需内缩量** ≥ 0.2mm（太小钩不住，太大压不进）

### B6 · 交付给用户看（🛑 节点 2）

把 `body.stl` / `lid.stl` / `shell.3mf` 三个文件**直接给用户**，并把上面的自检数值一起报出来。然后等答复。

**不要在同一条回复里既给文件又自己打开 App。** 用户点头后再走第 5 步。

## 4. 设计规则（都是有实测依据的）

### 4.1 配合间隙

| 场景 | 单边间隙 |
|---|---|
| 要能塞进去、不晃（默认） | **0.35 ~ 0.45 mm** |
| 要能轻松取出、经常开合 | 0.5 ~ 0.6 mm |
| 要紧配（不希望动） | 0.25 mm（有塞不进风险） |

FDM 打印（熔融沉积成型，就是拓竹这类挤出式打印机）的尺寸误差通常在 ±0.2mm，间隙低于 0.25mm 基本靠运气。

### 4.2 声学件三条铁律

麦克风靠**空气**传声。塑料包住它 = 捂住嘴。

| 铁律 | 具体做法 | 数字 |
|---|---|---|
| **1. 孔要开够** | 侧面敞开 / 大面积格栅 | 敞口面积 ≥ 物件投影面积的 **40%** |
| **2. 孔道要短** | 在板内侧做**沉台**（counterbore，把内壁挖掉一圈让孔变浅） | 有效孔长 ≤ **0.8 mm**。孔道一长，高频被衰减，人声发闷 |
| **3. 不能封死** | 别让内腔形成密闭气室 | 至少两个方向的开口 |

**孔位不确定怎么办**（不知道麦克风在物件的哪一侧）：**全方位开孔** —— 侧面四个方向都敞，顶底都开窗。牺牲一点强度和外观，换"怎么放都能收声"。

### 4.3 一体卡扣的经验值

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 卡钩突出量（半圆半径） | 0.6 ~ 0.8 mm | 太小钩不住，太大压不进 |
| 凹槽深度 | = 卡钩突出量 | 让钩完全嵌进槽 |
| 弹性臂厚度 | 1.2 ~ 1.6 mm | PLA 超过 1.8mm 就难弯了；PETG 可以厚一点 |
| 弹性臂宽度 | 10 ~ 14 mm | 越宽越难弯 |
| 滑动间隙 | 0.2 mm | 臂和墙之间的余量 |
| 压入内缩量 | 0.4 ~ 0.6 mm | = 突出量 − 滑动间隙。**低于 0.2mm 钩不住** |

### 4.4 壁厚

| 部位 | 值 |
|---|---|
| 顶板 / 底板 | 2.0 mm（要开窗的话别低于 1.6mm） |
| 侧墙 | 2.0 mm |
| 立柱截面 | 6 ~ 8 mm |

### 4.5 外形接近圆形时

`param_shell.py` 的外形是"圆角矩形"。**想做正圆壳**：让 `SHELL_W = SHELL_D = 直径`，同时 `CORNER_R = 直径 / 2`。

这种情况下把 `POST_ON` 关掉 —— 四角立柱会戳出圆外。

## 5. 踩坑清单（实测）

| 坑 | 症状 | 处理 |
|---|---|---|
| 圆角半径 ≤ 墙厚 | 圆角处墙被削穿，出现破洞 | 保证 `CORNER_R > WALL`（脚本会拦） |
| 沉台深度 ≥ 板厚 | 窗口被挖穿，模型破面 | 保证 `CB_D < PLATE`（脚本会拦） |
| 用 `--report` 前就出件 | 拿到一个尺寸错的模型 | **先 `--report`，数值对了再出件** |
| 弹性臂比内腔还长 | 盖上去顶到底板 | `ARM_L ≤ 内腔净高`（脚本会警告） |
| 只开一个方向的孔 | 声音闷、用户反馈"收不到声" | 至少两个方向开口 |
| 忘了把磁吸垫片/按键的凸起算进内腔 | 盖不上 | 内腔净高要按**凸起张开后的最大厚度**算 |
| 想让壳子能无线充电却用厚底板包住 | 充不进去 | 底板对应位置开孔或做薄 |

## 6. 环境说明（重要，别搞错方向）

- **用户什么都不用装。** 拖文件夹、说需求，流程和路径 A 完全一样。
- 需要 Python 几何库（trimesh / manifold3d / shapely / numpy）的是 **AI 这一侧**，由 `scripts/setup_env.py` 一次性准备好。
- **绝不要把 `pip install` 这一步交给用户。** 这是劝退开关。
- 国内网络装库慢时，加镜像：
  ```bash
  <venv>/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple trimesh manifold3d shapely numpy
  ```
